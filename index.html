My Projects

Dental Clinic OS - Clinic Management System

An offline-first desktop system that runs the full daily workflow of a real dental clinic and replaces paper records. The reception PC acts as a local server and the doctor's laptop pairs with it over the clinic network — queue, appointments and alerts sync instantly on both devices via WebSocket. It covers patient registration and search, appointments with booking codes, a live queue with a TV waiting-room display, patient files with visits, printable prescriptions and attachments, billing with partial payments, financial reports and daily closing, expenses, inventory, automatic backups and role-based access — and it receives online bookings from the clinic website.

Electron React + TypeScript Node.js (Express) PostgreSQL + Prisma Real-time Sync (WebSocket) Live Queue & TV Display Role-Based Access

Dental Clinic Website & Online Booking

The official website and online booking system for the clinic. A fast, Arabic-first, fully responsive site with services, the doctor's profile, FAQ and contact, plus a booking wizard (service → date → time → details) that shows live availability from Supabase with double booking prevented at the database level. Online bookings sync automatically to the clinic's desktop management system and alert the receptionist instantly.

Next.js 14 React + TypeScript Supabase (PostgreSQL) Row-Level Security Online Booking Wizard Double-Booking Prevention
